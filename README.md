# Ren logikk · Czysta logika · Pure Logic

Free mobile-first browser number puzzle by Stop60, inspired by the classic number-placement puzzle:
fill in the digits 1–9 so that none repeats in any row, column or 3×3 box.

- Single self-contained `index.html` (inline JS/CSS, embedded stop60.no fonts and QR generator, works offline once loaded)
- Languages: Norsk (bokmål, default), Polski (`/pl/`), English (`/en/`), switch in the header; `?lang=no|pl|en`
- Levels easy / medium / hard (every board has exactly one solution and is rated by a human-style solver), daily puzzle (same for everyone, date-seeded)
- Number pad, pencil notes, undo, erase, 3 hints per board, optional mistake highlighting, optional timed mode (off by default), autosave
- Free, no ads, no account, no cookies
